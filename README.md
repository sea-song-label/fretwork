# Fretwork

ギターの基礎練習用ツール。指板のパターンをタブ譜として自動生成し、メトロノームに同期してスクロールします。マイクを使うと、弾いた音が合っているかを判定します。

**Sea Song Label / Forge**

## 使い方

1. プリセットを選ぶか、「パターンを作る」で開始弦・フレット・形状を指定して生成する
2. BPMを決めて「▶ 再生」
3. タブ譜が自動でスクロールし、いま弾く音が青く光る

### マイクで音程を判定する

「🎤 マイクでチェック」を押してマイクを許可すると、光っている音と実際に弾いた音を比べ、違っていれば**赤く**表示されます。

- 判定は**音名**で行います。同じ音名ならオクターブ違いも正解扱いです（同じ音が指板の複数箇所にあるため）
- 許容範囲は±40セント（半音の4割）
- **単音の練習用**です。和音は判定できません
- 「音を鳴らす」をオンにしたままだとアプリ自身の音を拾うため、マイク判定中はオフにするかイヤホンを使ってください

### 手癖をしらべる

メトロノームを止めて自由に弾くと、弾いた音を溜めて**音の選び方の癖**を出します。よく居る音域・音の跳び方・使っている音・フレーズの終わり方の4点です。そのうえで、**普段使っていない音を、普段しない動き方で並べた練習**を作ります。

上手い下手を測るものではなく、「いつもこうしている」を見るためのものです。

> **原理上の制約**：マイクから取れるのは音の高さだけで、同じ音が指板の複数箇所にあるため（E4＝1弦開放／2弦5F／3弦9F…）、**どの弦のどのフレットを押さえたかは特定できません**。したがってここで見るのは指板上の位置ではなく音の選び方です。

### 押さえた音を鳴らす（Your Voicing）

指板で押さえた形を「▶ 鳴らす」で鳴らします。音色は「クリーンのエレキギター」と「ローズ」から選べます（選んだ音色は次に開いたときも残ります）。

- 低い音から順に鳴らします。ギターはジャランと少しずらし、ローズはほぼ同時に鳴らします
- カポを付けているときは、カポの分を足した実際の高さで鳴ります
- 音の素材は読み込まず、ページの中で作っています（ギター＝弦をはじく音の計算、ローズ＝電気ピアノの定番の作り方）。電波の無いところでも鳴ります
- iPhoneで音が出ないときは、本体の消音スイッチ（マナーモード）を切ってください

### ほかのページから和音を渡して開く

`?root=0&iv=0,4,7,11&bass=0&name=Cmaj7#voicingPanel` のように、根音（0〜11。0＝C）・根音からの音程（カンマ区切り）・低い音（0〜11）・和音名を渡すと、「Find a Voicing」がその和音で開きます（pet sounds の五線譜から使う）。

- 受け取るのは数字だけ。和音名は文字として表示するだけです
- 5音以上の和音は指4本では全部押さえられないことが多いので、5度と根音を省いた形も出します（「根音を省略」の札）
- 低い音が根音と違うとき（分数和音）は、いちばん低い音がその音の形だけを出します

### iPhone / iPad

Safariで開き、共有ボタンから「ホーム画面に追加」すると、アプリのように起動できます。横向きにするとタブ譜が画面いっぱいに広がります。

### Macでローカルに動かす場合

`Fretwork起動.command` をダブルクリックすると簡易サーバーが立ち上がります。
`index.html` を直接開く方式（file://）では、ブラウザの制約でマイクが使えません。

## 技術メモ

- 単一のHTMLファイル。ビルド不要・依存ライブラリなし
- メトロノームはWeb Audio APIの先読みスケジューラ方式
- 音程検出は自己相関法（RMSで無音判定 → トリム → 自己相関のピークを放物線補間）
- 練習中に画面が消えないようScreen Wake Lock APIを使用

パターンの形状（下降形・上昇形・ジグザグ）は独自の設計です。
